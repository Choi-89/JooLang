# JooLang

> **지역 사회 내에서 불필요한 물품을 필요한 사람들에게 무료로 제공하고, 재사용 문화를 촉진하는 것을 목표로 하는 온라인 플랫폼입니다.**

**JooLang**은 지역 내에서 더 이상 사용하지 않는 물품을 필요한 이웃에게 무료로 나눔으로써, 자원 재순환과 친환경 문화를 만들고자 하는 커뮤니티 플랫폼입니다.

---

## 👥 팀 역할 분담

총 6명의 팀원이 아래와 같이 역할을 맡았습니다.

1. **백엔드 (Server)**
   - 서버 및 데이터베이스 설계/구현
   - API 개발 및 관리
2. **프론트엔드 (Web)**
   - 웹 서비스 UI/UX 구현
   - 사용자 인터페이스 개발
3. **디자인**
   - 플랫폼 디자인 및 시각 자료 제작
   - 로고/아이콘/이미지 등 디자인 자산 관리
4. **Plan**
   - 프로젝트 기획 및 일정 관리
   - 요구사항 정의 및 문서화

---

## 🙋‍♂️ 담당 역할: 회원 정보 관리

- 회원 가입/로그인/정보 수정/탈퇴 등 회원관리 기능 개발
- 회원 데이터의 안전한 저장 및 보호
- 사용자 경험을 고려한 UI/UX 설계

## 🛠️ 사용 기술

- **Backend:** Java (Spring 등)
- **Frontend:** HTML, CSS, JS
- **Design:** Figma, Photoshop 등
- **Version Control:** GitHub
